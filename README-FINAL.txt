LUXURY TRANSPORT DUBAI — COMPLETE NON-ZIINA WEBSITE PACKAGE

This package contains the consolidated website files through the current redesign.
Ziina webhook/payment verification has intentionally NOT been changed.

- Short mobile-first home dashboard
- Separate Booking, Tracking, Services, About and Contact pages
- Customer login, signup, password reset and protected My Account
- Customer saved locations
- Customer 15-minute inactivity logout with warning
- Admin inactivity protection (default 5 minutes, settings-driven)
- Existing admin, tracking and payment frontend preserved
- Optional multi-stop booking UI
- Existing School/Recurring entry point preserved
- Existing Supabase configuration preserved
- final-non-ziina.sql for the guest multi-stop helper required by the new booking UI

IMPORTANT:
Run final-non-ziina.sql once in Supabase SQL Editor if you want guest multi-stop booking storage enabled.
